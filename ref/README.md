# ref: drop folder for material from devices

Put recordings, exports and other reference material from the iPad or the Mac here. Nothing in this folder is
committed (`.gitignore` keeps everything but this file out; the repository is public and a recording is the DJ's own
content, D3). Recordings are moved to `~/Music/Deckie/Sets/<date and name>/` on this Mac and analysed from there; the
analysis letters and their derived tables, never the audio, go under `docs/research/`.

Moved so far: the 35 booth recordings of the Oct 24, 2026 set (`ref/From ipad/Haloween /Sets/`, 464 MB) to
`~/Music/Deckie/Sets/2026-10-24 Halloween/`.
