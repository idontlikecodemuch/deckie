# Name check (Oct 26, 2026): Deck, DJ-I, E-DJ, Deckhand

Method: Apple iTunes Search API (US storefront, live); DNS/RDAP for domains (indicative only); trademarks via aggregators only (unverified; run USPTO TESS and EUIPO eSearch before committing). Google Play not queried.

## Deck
- App Store: no exact "Deck" in Music; crowded generic slot (Deck presentation remote, Deck meme coins, Deck-Man cassette player, Elgato Stream Deck, card games). DJ neighbours: OpenDeck DJ, SetDeck: DJ Recorder (closest functional rival, records sets), Decks Network (DJ profiles, July 2026), Deckadance (older).
- Trademark: common word, crowded (Stream Deck, Steam Deck); a bare "Deck" for DJ software would be descriptive and weak. Unverified.
- Domains: deck.app, deck.dj, deck.io, getdeck.com, deckapp.com (parked/for sale), deck.com all registered.
- DJ usage: "deck" = the player itself; DJs read it as hardware, findability near zero.
- Sound: short, punchy, natural in a booth.
- Score: distinctiveness 1, availability 1, fit 3. Verdict: great word, unownable and unfindable.

## DJ-I / DJI
- App Store: swamped by SZ DJI Technology's drone apps (DJI Fly, Mimo, Go4, Ronin, Store).
- Trademark: famous mark DJI (USPTO reg 4535405 class 9, reg 4888933; EUIPO 014536395); DJI also sells audio (Mic line). Risk high: identical in sound and look; dilution/confusion plausible.
- Domains: dji.app (for sale), dji.io, dji.com (DJI), djiapp.com (for sale), dj-i.com (parked); dj-i.app/.io/.dj apparently open (unverified).
- DJ usage: reads like a Pioneer "DDJ-" controller code or drones; "dee-jay-eye" is clunky and spelling varies.
- Score: 2 / 1 / 2. Verdict: do not use.

## E-DJ / EDJ / eDJ
- App Store: direct phonetic/spelling collision with edjing (MWM; Edjing Mix, edjing Pro; ~30M users; iOS and Android). Also WeDJ, YouDJ, DJ it!.
- Trademark: EDJING marks likely held by MWM (unverified); "E-" prefix names are weak and dated.
- Domains: edj.app, edj.io, edj.com registered; e-dj.com parked for sale; edj.dj, e-dj.dj/.app/.io, getedj.com, edjapp.com apparently open (unverified).
- DJ usage: DJs would assume edjing or a copy; "electronic DJ" connotation.
- Score: 2 / 2 / 2. Verdict: too close to edjing, too generic.

## Deckhand
- App Store: four exact/near-exact names, none in Music: Deckhand Pro (fishing logbook), Deckhand: Boat Wash & Detail, DeckHand Pool Service, Deckhand! (utilities); also Deckhand ops software (Capterra). No DJ or Music app named Deckhand.
- Trademark: other publishers may hold rights in other classes (boat services, logbook); coexistence plausible but class 9/42 overlap needs a knockout search. Moderate risk.
- Domains: deckhand.app, .io, .com, getdeckhand.com, deckhandapp.com registered; deckhand.dj apparently open (unverified).
- DJ usage: none found; reads as "the helper at the decks", understood at once.
- Sound: memorable, warm, describes the role (helper, not the star), avoids AI hype; "ask Deckhand"; low spelling risk; mild nautical association.
- Score: distinctiveness 4 (DJ context) / availability 2 / fit 5. Verdict: best of the four; use a descriptive subtitle ("Deckhand: DJ Set Assistant"); clear the trademark before launch.

## Summary
Deck 1/1/3 · DJ-I 2/1/2 · E-DJ 2/2/2 · Deckhand 4/2/5. Recommendation: Deckhand; drop DJ-I and E-DJ; Deck alone is unownable.
