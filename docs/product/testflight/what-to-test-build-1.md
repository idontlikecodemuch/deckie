# What to test, build 1 (draft)

Thanks for trying the first build. Please try these and tell us how each went:

1. **First open.** With no crate file, Booth shows what it does and three steps. Is it clear what to do next?
2. **Getting a crate file in.** Make one with Deckie Desk, send it to the iPad by AirDrop or save it to Files, then
   open it (tap "Open a crate file", or open it from Files). Did it open? How long did it take?
3. **Naming the song.** Play from your crate in the room. Does Booth name the right song, and how soon? Does it keep
   up when you mix from one song to the next?
4. **The picks.** Would you play any of them next? Is the pitch it suggests close to where you set your fader?
5. **Locked iPad.** Lock the iPad during a set and unlock it later. Did it keep listening, and is the set's
   recording complete in Files under Deckie Booth > Sets?
6. **Setting a song by hand.** When the room is too loud, tap a song in the Crate tab. Do the picks follow?

Known in this build:

- There is no demo crate yet: you need a crate file from Deckie Desk to see anything past the first screen.
- A crate file made on a Windows PC has no song fingerprints yet, so Booth cannot name songs from it: set them by hand
  in the Crate tab.
- The look and the words are still being worked on.
